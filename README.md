# appaday-193-cornhole-scorekeeper
Cornhole Scorekeeper is a backyard scoreboard for singles or doubles. Enter each frame’s woodies and cornholes and cancellation scoring nets the difference, with a live preview before you commit. Play to 11, 15, 21 or 25 with an optional bust rule, edit any frame, run best of 3 or 5 series, and keep a match history.
